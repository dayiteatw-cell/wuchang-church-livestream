正面主鏡 Galaxy A27 架設於距離講台 4 米處，為避免影音同工在音控桌與講台間頻繁奔走，請務必遵循以下電源與連線四大守則：

🔌 1. 邊播邊充：插主機後方【藍色 USB 3.0 孔】

• 藍色 USB 3.0 (SS)：供電 5V / 0.9A~1.5A，電力充足，2 小時直播電量收支平衡或越充越滿！
• 避免前面板黑孔 (USB 2.0)：僅 0.5A 供電不足會緩慢掉電。

🛡️ 2. 防電池膨脹老化：開【三星 80% 電池保護】

• 設定：手機「設定」➔「電池」➔ 開啟「電池保護」設為【最大 (80%)】。
• 效果：充到 80% 物理斷電，壽命延長 4 倍且 100% 不膨脹！平日電腦關機 USB 斷電，5000mAh 休眠 7 天僅耗電約 30%，週日開機自動補電。

⚠️ 3. 電源控制：徹底關機指令 vs 遠端休眠

• 徹底關機指令（長假保養）：執行 adb -d reboot -p（或在 Scrcpy 視窗按 Ctrl+P 點選關機），手機即安全存檔並完全關閉電源。
• ⚠️ 徹底關機警語：手機徹底關機後無法透過 USB 遠端開機，下次使用必須走至腳架旁按手機實體電源鍵開機！
• 平日最佳解法（免離座休眠/喚醒）：電腦做捷徑執行 adb -d shell input keyevent 26，平日按一下熄屏深層休眠，週日按一下喚醒點亮！

📱 4. Scrcpy 熄屏操控與多手機無衝突隔離

• 螢幕熄滅黑科技：執行 scrcpy --turn-screen-off，電腦能滑鼠滾輪縮放 (Zoom) 與點擊對焦，手機實體螢幕全黑不發熱。
• 雙安卓機無衝突隔離：捷徑工具已精準配置 -d（只綁定 USB 有線主鏡 Galaxy A27）與 -e（只綁定 Wi-Fi 無線安卓機），兩台同時在線也絕不衝突報錯！

🎯 6. Iriun 多手機編號（#1 / #2 / #3）綁定規則 ＆ 啟動後快速對調秘訣

🔍 7. 如何取得 A27 有線序號 ＆ ASUS 無線 IP，並順利寫入 BAT 腳本？

許多同工疑惑：「BAT 腳本是怎麼知道哪台是 A27、哪台是 ASUS 的？」答案是透過 Android ADB 的專屬裝置識別機制：

🔌 A27 有線手機（USB 專屬識別）
  • 【免查序號極致解法（最推薦）】：
    在 BAT 腳本中使用 adb -d 參數（-d 代表 Direct to only USB device）。因為 iPhone X 為 iOS 不走 ADB，電腦插線的安卓手機永遠只有 A27 一台！只要加 -d，ADB 永遠 100% 只會控制 A27，完全不需要手動查序號，換 USB 線也能直接用！
  • 【若想手動查詢實體序號】：
    插上 USB 線，在電腦終端機輸入 adb devices，顯示如 R58M30XYZAB device，前面那一串代碼即為 A27 的專屬硬體序號。
📶 ASUS 會眾機（5GHz Wi-Fi IP 綁定）
  • 【取得無線編號（IP 與 Port）】：
    在 ASUS 手機「設定」➔「關於手機」➔「狀態資訊」查看 Wi-Fi IP（例如 192.168.1.50），它的 ADB 無線編號即為 192.168.1.50:5555。
  • 【如何寫入 BAT 腳本？】：
    捷徑工具目錄下已有 asus_ip.txt 檔，BAT 腳本開頭會自動讀取 set /p ASUS_IP=<"asus_ip.txt"，並以 adb -s %ASUS_IP%:5555 精準發送指令給 ASUS。
  • 【一鍵自動綁定工具】：
    點擊 【工具】一鍵查詢相機編號與綁定.bat，輸入新 IP 後自動測試連線並同步更新到所有腳本！

⚠️ 重要硬體限制說明：
教會電腦顯卡為 NVIDIA GeForce GTX 1650。請注意：NVIDIA Broadcast 軟體強制要求 RTX 2060 以上顯卡（具備 Tensor Core AI 晶片），在 GTX 1650 上無法安裝。針對現場設備，我們採用以下最穩健的配置方案：

一、 走動追焦的最佳解法：正面距離 4 米「1.0x 舞台安全框」（零負擔、最推薦！）

在距離講台 4 米處，Galaxy A27 的 1.0x 鏡頭視野寬度高達 5.4 公尺，已將整座講台與兩側走廊 100% 吃滿：
• 牧師不管向左走、向右走，整場講道人永遠都在鏡頭內，絕不出鏡！
• 在 OBS 來源中直接選取 Iriun Webcam #1，不需要任何額外軟體轉接，不耗費顯卡算力，穩定度 100%，畫質最純淨！

二、 若仍希望鏡頭自動追焦：改用 OBS 免費外掛「OBS Face Tracker」

如果仍希望畫面能隨牧師走動自動推拉，請改用不限顯卡的開源外掛 obs-face-tracker：
1. 下載並安裝開源外掛 obs-face-tracker。
2. 在 OBS 的 Galaxy A27 來源點右鍵 ➔ 濾鏡 (Filters) ➔ 效果濾鏡點 + ➔ 新增 Face Tracker。
3. 縮放 (Zoom) 設為 1.2x，平滑度 (Smoothing) 設為 85%，即可在 GTX 1650 上順暢運作！

三、 發揮 GTX 1650 的真正王牌：【啟用 NVENC 獨立硬體編碼】（最關鍵！）

GTX 1650 內建專用 NVENC 硬體編碼晶片，務必在 OBS 開啟，能讓 CPU 負載直接降到 10% 以下：
