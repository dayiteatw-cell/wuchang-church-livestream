# 五常基督長老教會・主日同工投影與直播教學手冊及影音中控系統

本專案為**五常基督長老教會**打造的一站式主日現場影音總控與同工操作標準流程（SOP）。旨在精簡繁雜步驟、建立高度自動化的禮拜直播與投影流程，讓服事同工能夠輕鬆上手、專注敬拜。

---

## 🌟 核心特色

1. **極簡 9 步同工實戰教學手冊**：
   - 包含單一離線可用之互動式 HTML 教學手冊 (`五常教會主日同工投影與直播教學手冊.html`)。
   - 所有實機操作截圖與重要紅框標註均內嵌 Base64，開箱即看、無須聯網。
   - 燈箱放大功能，點擊任一截圖即可細看操作介面細節。

2. **OBS 崇拜全程自動化**：
   - **定時解靜音**：開啟時預設靜音，主日早上 10:00 自動解除靜音並開始收音。
   - **PPT 換頁自動滿版**：當 PowerPoint 簡報翻頁時，OBS 場景自動跳轉為【主日 PPT 滿版】，停留 28 秒後自動切回正面主鏡，翻到下一頁時自動歸 0 重新計數。
   - **雙機位自動輪播**：正面主鏡停留 90 秒後，自動切換至側面副鏡（iPhone X 特寫）停留 18 秒，隨後自動跳回主鏡。
   - **保留手動彈性快捷鍵**：
     * `F1`：正面主鏡（牧師講道）
     * `F2`：側面副鏡（講台特寫）
     * `F3`：會眾全景（會堂大景）
     * `F4`：主日 PPT 滿版

3. **五常主日影音中控系統 (Python / Tkinter / PyInstaller)**：
   - 整合手機遠端相機操控 (scrcpy / Iriun Webcam)。
   - 一鍵自動下載當週主日附件郵件。
   - 自動生成當日標準 YouTube 直播標題並一鍵複製。
   - PowerPoint 雙螢幕延伸投影與放映。
   - 雲端詩歌同步與智慧置頂懸浮導航視窗。
   - 一鍵自動完成桌面「四分割黃金工作台」排版。

## 🚀 快速開始

### 查看教學手冊
直接在瀏覽器中開啟 `五常教會主日同工投影與直播教學手冊.html` 即可完整閱覽。

### 重新編譯手冊
若有更新素材或文字，可執行：
```bash
python build_full_sop_html.py
```
即會自動將圖片轉為 Base64 並重新打包成單一離線 HTML 檔案。
